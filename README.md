# Óxido

Juego de gestión de colonia postapocalíptica para navegador, en pixel art y vista cenital, inspirado en RimWorld. Jugable en móvil y PC.

**Jugar:** https://mikeljka.github.io/OxidoGame/

## Desarrollo

```bash
npm install
npm run dev     # servidor local
npm test        # tests
npm run build   # build de producción
```

Diseño en `docs/DISENO.md`, tareas en `docs/ROADMAP.md`, diario en `docs/PROGRESO.md`. Las instrucciones para Claude están en `CLAUDE.md`.
